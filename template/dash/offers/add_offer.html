Help Desk

A Coupon requires the customer to enter a code at checkout — e.g. RAWWISH10. An Automatic offer is applied silently when the cart meets the condition — e.g. free shipping when cart is above ₹499. Use coupons for marketing campaigns and automatics for always-on deals.

Set Trigger to Automatic, Condition to Minimum Order Amount (e.g. ₹499), and Action to Free Shipping. This will automatically waive shipping for any cart above ₹499 — no code needed from the customer.

Set Action to Buy X Get Y Free. Enter the buy quantity (e.g. 2) and get quantity (e.g. 1). For example — Buy 2 packs of Mysore Nuggets, Get 1 Sample Pack Free. Use Condition to restrict it to a specific product or category if needed.

A Bundle lets you group specific products and sell them together at a fixed price. For example — select Filter Cosmetics Powder, Cold Routine Ground Cosmetics, and Espresso Blend, then set a bundle price of ₹599 instead of the combined ₹749. Select multiple products using Ctrl or Cmd.

If Stackable is set to Yes, this offer can combine with other active offers on the same order. For example, a Free Shipping offer can stack with a 10% off coupon. Set to No to prevent double discounting. Priority determines which offer is applied first when stacking.

The Max Discount Cap limits how much a percentage discount can give. For example, if you set 20% off with a cap of ₹200 — a ₹1500 order would normally get ₹300 off, but the cap limits it to ₹200. This protects your margins on high value orders.
